SSH 連線

使用電腦內建的 ssh，金鑰與 ~/.ssh/config 照常生效；要密碼時會在終端機裡問，panex 不會儲存。

啟用 Claude Code 通知？

Claude Code 需要你處理或做完時，分頁會亮起；關掉重開後也能一鍵恢復 session。

會在 ~/.claude/settings.json 加入 panex 的 hooks，寫入前先備份，你原本的 hooks 都會保留。

    設定

    改動會立即套用並存進 panex.json

    語言介面語言，自動 = 跟隨系統
    不透明度文字永遠清楚，只有背景會變透明
    背景效果透出桌面的模糊或色調，需要不透明度低於 100%
    字型大小也可以用 Ctrl+滾輪調整
    視窗大小每次開啟時的寬 × 高，改了立刻套用
    ×
    快捷鍵提示按住 Ctrl 或 Alt 時，在工作區與分頁上顯示快捷鍵編號
    字型列出已安裝的等寬字型；中文與 emoji 會自動用備援字型補上
    C:\Users\you>~/projects % claude　中文對齊 0O lI1 ⚠ ✨
    新分頁用的 shell⌄ 選單隨時可以開別的
    智慧複製貼上有選取時 Ctrl+C 複製，沒選取仍是中斷；Ctrl+V 貼上
    重開後接回 Claude Code重開 panex 時，上次還在跑 Claude Code 的分頁會自動執行 claude --resume
    agent 工作中關閉前先確認有 Claude Code 正在跑時關閉 panex 或它所在的分頁，先問一聲，免得誤關中斷它
    用什麼開啟檔案路徑按住 Ctrl 點終端機裡的檔案路徑時用它開；選編輯器會跳到行號
    游標閃爍關掉比較省電
    捲動歷史每個分頁保留的行數，越多越吃記憶體；新分頁才生效
    行

    panex.json所有設定都存在這個檔案。用編輯器改完存檔，約 0.3 秒後自動套用；旁邊的 panex.schema.json 讓 VS Code 有自動完成。
    快捷鍵寫法字串是一組按鍵，陣列是依序按的連續按鍵，陣列裡放陣列代表多組任選一組，null 代表不綁定。
    "shortcuts": {
  "bindings": {
    "newTab": [["ctrl+n"], ["ctrl+t"]],
    "renameTab": "f2",
    "nextTab": ["ctrl+k", "ctrl+n"],
    "clearScrollback": null
  }
}
